## Requirement Clarity & Mathematical Precision

- [x] CHK005 Is the `apply_onset_jitter` window index calculation unambiguously specified, including sampling $\delta \in [-\text{max\_jitter\_samples}, +\text{max\_jitter\_samples}]$, computing `jittered_center = (center_sample as isize + delta).max(0) as usize`, computing `raw_start = jittered_center.saturating_sub(pre_len)`, clamping `start` so `start + win_len <= full_samples.len()`, and re-normalizing via `normalize_peak`? [Clarity, Spec §FR-009.1, Research §5.1]
- [x] CHK006 Is the `add_background_noise` mathematical formulation unambiguously specified, including signal power $P_{\text{sig}} = \frac{1}{N}\sum_{i=0}^{N-1} x_i^2$, uniform sampling of $\text{SNR}_{\text{dB}} \in [\text{lo}, \text{hi}]$, noise standard deviation $\sigma_{\text{noise}} = \sqrt{P_{\text{sig}} \times 10^{-\text{SNR}_{\text{dB}} / 10}}$, Box-Muller Gaussian white noise generation $z \sim \mathcal{N}(0, 1)$, and final peak normalization via `normalize_peak`? [Clarity, Spec §Clarifications, Spec §FR-009.2, Research §5.2]
- [x] CHK007 Is the Box-Muller transform in `add_background_noise` specified with a strictly positive lower bound on $u_1$ (e.g., $u_1 \in [10^{-7}, 1.0)$, $u_2 \in [0.0, 2\pi)$, $z = \sqrt{-2 \ln u_1}\cos(u_2)$) so $\ln(u_1)$ can never evaluate $\ln(0.0) = -\infty$? [Clarity, Research §5.2]
- [x] CHK008 Is the `apply_spectral_tilt` row-wise offset formula ($\Delta_m = \frac{\text{tilt\_db}}{\text{top\_db}} \times \left(\frac{2m}{M - 1} - 1\right)$ for Mel row $m \in [0, M - 1]$ where $\text{tilt\_db} \in [-|\text{max\_tilt\_db}|, +|\text{max\_tilt\_db}|]$) and post-addition `[0.0, 1.0]` clamping rule explicitly defined? [Clarity, Spec §FR-009.3, Research §5.3]
- [x] CHK009 Are the `apply_spec_augment` mask width caps ($f_{\text{mask}} \in [0, \min(\text{max\_freq\_mask}, M / 4)]$ and $t_{\text{mask}} \in [0, \min(\text{max\_time\_mask}, T / 4)]$), starting index bounds ($f_0 \in [0, M - f_{\text{mask}})$ and $t_0 \in [0, T - t_{\text{mask}})$), and replacement value (`noise_floor_val = 0.0` corresponding to `-80 dB`) unambiguously specified? [Clarity, Spec §FR-009.4, Research §5.4]

- [x] CHK023 Is the behavior of `apply_spectral_tilt` explicitly specified for degenerate parameters (`max_tilt_db == 0.0`, negative `max_tilt_db`, non-finite `max_tilt_db`, `top_db <= 0.0`, or matrices with `nrows() <= 1`), ensuring zero division-by-zero (`M - 1 == 0`) or inverted random-range panics?
