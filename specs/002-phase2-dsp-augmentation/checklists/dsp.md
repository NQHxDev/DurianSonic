- [x] CHK010 Is the mapping from RMS frame index $i$ to sample position (`center_sample = i * 256`), refractory gap enforcement (`center_sample - prev_center >= 8,820` samples / `0.4s`), pre-onset lead-in (`start = center_sample.saturating_sub(2,205)` / `100 ms`), and full-window boundary check (`start + 17,640 <= samples.len()`) explicitly quantified? - [x] CHK013 Are the exact STFT time-frame slices for the 4 physics features unambiguously differentiated between the primary impact window (`t in 0..64`, first `64` frames for $\tilde{f}_{\text{peak}}$, $\tilde{C}_s$, $\tilde{R}_{85}$) and the inclusive decay tail (`t in 26..=86`, `61` frames corresponding to ~`50 ms` to ~`400 ms` after onset peak for $\tilde{\beta}_{\text{decay}}$)? - [x] CHK014 Is the Ordinary Least-Squares (OLS) linear regression slope formula for $\beta_{\text{decay}}$ ($\beta_{\text{decay}} = \frac{\sum (t - \bar{t})(E_{\text{dB}}(t) - \bar{E})}{\sum (t - \bar{t})^2 + 10^{-8}}$ in dB/frame, where $E_{\text{dB}}(t) = 10\log_{10}(\sum_k P(k, t) + 10^{-10})$) and its sign-inverted normalization ($\text{clamp}(-\beta_{\text{decay}} / 2.0, 0.0, 1.0)$) explicitly specified?
